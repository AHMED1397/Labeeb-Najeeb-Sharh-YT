📚 How to Add a New Book

1. Create a folder inside Books/, e.g. Books/My_Book/
2. Place HTML lecture files with a consistent naming pattern, e.g. my_book_lecture1.html
3. Register the book in lib/data.ts — add an entry to bookRegistry[] with:
   - dir: folder name (e.g. "My_Book")
   - slug: URL slug (e.g. "my-book")
   - title / titleAr: book name
   - author / lecturer: author and lecturer names
   - description: short description
   - icon: emoji icon
   - filePattern: regex to match lecture files (e.g. /my_book_lecture(\d+)\.html$/)
   - subtitleClass: the class used for the lesson subtitle in the HTML (usually "subtitle" or "cover-subtitle")
4. Add YouTube links in lib/youtube.ts under the matching slug key
5. Rebuild: npm run build
6. Commit and push to deploy on Vercel

📝 Important Notes
- HTML files are served as-is via an iframe — all your <style>, <script>, @font-face, and HTML work exactly as a standalone page
- The @font-face blocks referencing local TTF files are automatically removed (Google Fonts handles them)
- Use font-family: 'Amiri' and 'Noto Naskh Arabic' (not 'Amiri-Bold' or 'NotoNaskhArabic') for best Google Fonts compatibility
- YouTube links array index = lesson number - 1 (zero-based)
- No code changes to HTML files are needed
